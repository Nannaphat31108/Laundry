# ระบบจัดการร้านซักรีด

เว็บแอป (PWA) สำหรับร้านซักรีด ใช้บนแท็บเล็ต มือถือ หรือคอมพิวเตอร์ ไม่ต้องมีเซิร์ฟเวอร์ ข้อมูลเก็บในเครื่อง (localStorage)
และใช้งานออฟไลน์ได้

ฟีเจอร์ทั้งหมดมาจากระบบเดิม แต่ออกแบบ UX/UI ใหม่ด้วยโทนสีสดใส

## ฟีเจอร์

| หน้า | ความสามารถ |
|---|---|
| หน้าหลัก | รายรับวันนี้ (เทียบเมื่อวาน), ปุ่มลัด, สถิติ, กราฟรายรับ 7 วัน, ลูกค้าที่ต้องติดตาม (แพ็คเกจใกล้หมด/ใกล้หมดอายุ) พร้อมปุ่มต่อแพ็คเกจ, ใบเสร็จล่าสุด |
| รับผ้า / คิดเงิน | เลือกลูกค้าแบบค้นหาได้, รายการคิดตามชิ้น (แตะการ์ดเพื่อเพิ่ม) และตามน้ำหนัก (กก.), หักจากแพ็คเกจอัตโนมัติ, ตัวเลือกต่อแพ็คเกจใหม่เมื่อชิ้นเกิน, สรุปยอด, บันทึก + พิมพ์ใบเสร็จ |
| ลูกค้า | ค้นหาชื่อ/เบอร์/ไลน์ไอดี, ตัวกรองตามสถานะแพ็คเกจ, เพิ่ม/แก้ไข/ลบ, แก้ยอดคงเหลือและวันหมดอายุ, ซื้อ/ต่อแพ็คเกจ |
| แพ็คเกจ | เพิ่ม/แก้ไข/ลบ (ชื่อ ประเภท จำนวนชิ้น ราคา จำนวนวัน), แสดงราคาเฉลี่ยต่อชิ้นและจำนวนลูกค้าที่ใช้งาน |
| ใบเสร็จ | กรองช่วงวันที่ + ค้นหา, ดู/พิมพ์ซ้ำ (80mm), ยกเลิก (ตัดยอดออกจากบัญชี), ลบถาวร |
| บัญชี | รายรับ/รายจ่าย, ช่วงเวลาด่วน (เดือนนี้ / 3 / 12 เดือน), กราฟรายเดือน, แยกตามหมวดหมู่, ส่งออก Excel (CSV), รายงานสรุป A4 (พิมพ์/PDF) |
| ผู้ดูแลระบบ (แอดมิน) | ป้องกันด้วยรหัส PIN · ข้อมูลร้าน โลโก้ QR · รูปแบบใบเสร็จ (แสดง/ซ่อนราคาต่อชิ้น, ตัวอักษรนำหน้าและเลขลำดับใบเสร็จ) · ราคาต่อชิ้นและลำดับรายการ · แพ็คเกจ (แก้ในตาราง) · หมวดรายรับ/รายจ่าย/ประเภทแพ็คเกจ · กฎระบบ (เกณฑ์แจ้งเตือน, วิธีจัดการชิ้นเกินแพ็คเกจ, เวลาล็อกอัตโนมัติ) · เปลี่ยนรหัส · สำรอง/กู้คืน/ล้างข้อมูล |

### สิทธิ์แอดมิน

พนักงานใช้งานได้ปกติ (รับผ้า เพิ่มลูกค้า ขายแพ็คเกจ พิมพ์ใบเสร็จ เพิ่มรายรับ/รายจ่าย)
ส่วนต่อไปนี้ต้องกรอกรหัสแอดมินก่อน: หน้าผู้ดูแลระบบ, แก้/ลบแพ็คเกจ, แก้แพ็คเกจ-ยอดคงเหลือ-วันหมดอายุ-ลบลูกค้า,
ยกเลิก/ลบใบเสร็จ, แก้/ลบรายการบัญชี — ครั้งแรกระบบจะให้ตั้งรหัส PIN 4–6 หลัก และล็อกอัตโนมัติเมื่อไม่ได้ใช้งาน

> รหัสเก็บแบบเข้ารหัส (hash) ในเครื่อง ใช้กันการแก้ไขโดยไม่ตั้งใจของพนักงาน ไม่ใช่ระบบความปลอดภัยระดับเซิร์ฟเวอร์

## เครื่องพิมพ์ใบเสร็จ (Xprinter XP-N160II)

ตั้งค่าที่ ผู้ดูแลระบบ → เครื่องพิมพ์ (ตั้งแยกแต่ละเครื่อง) ใบเสร็จถูกวาดเป็นรูปขนาด 576 จุด (80mm, 203dpi)
แล้วส่งเป็นคำสั่ง ESC/POS raster จึงพิมพ์ภาษาไทยได้ถูกต้องโดยไม่ต้องตั้งค่าตัวอักษรในเครื่องพิมพ์

| อุปกรณ์ | วิธีที่แนะนำ |
|---|---|
| คอมพิวเตอร์ Windows/Mac | หน้าต่างพิมพ์ของเบราว์เซอร์ (ติดตั้งไดรเวอร์ Xprinter) หรือ USB โดยตรง (Chrome/Edge) |
| แท็บเล็ต/มือถือ Android (เช่น Xiaomi) | **ไม่ต้องติดตั้งแอป:** Bluetooth โดยตรง (เครื่องพิมพ์ต้องรองรับ Bluetooth LE) หรือ USB โดยตรงผ่านสาย OTG — ใช้ Chrome · หรือแอป RawBT |
| iPhone / iPad | บันทึกเป็นรูปภาพ แล้วแชร์ไปพิมพ์ด้วยแอปของเครื่องพิมพ์ |

ตัวเลือก: ขนาดกระดาษ 80/58mm, ขนาดตัวอักษร, จำนวนสำเนา, ฟีดกระดาษ, ตัดกระดาษอัตโนมัติ, พิมพ์อัตโนมัติหลังบันทึกบิล, เปิดลิ้นชักเก็บเงิน

## ติดตั้งเป็นแอปบนมือถือ/แท็บเล็ต

กดปุ่ม “ติดตั้งเป็นแอป” (เมนูด้านข้าง หรือ เมนูเพิ่มเติม บนมือถือ) — Android/คอมพิวเตอร์ติดตั้งได้ทันที,
iPhone/iPad ใช้ Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม

## ย้ายข้อมูลจากระบบเดิม

ระบบนี้ใช้โครงสร้างข้อมูลเดียวกับระบบเดิม
1. ที่ระบบเดิม: ตั้งค่าร้าน → **ดาวน์โหลดไฟล์สำรอง**
2. ที่ระบบนี้: ผู้ดูแลระบบ → ข้อมูล & รหัส → **กู้คืนจากไฟล์** แล้วเลือกไฟล์ `.json`

## การใช้งาน / Deploy

เป็นไฟล์ static ทั้งหมด จึงเปิดผ่าน GitHub Pages หรือเว็บเซิร์ฟเวอร์ใดก็ได้

```bash
npx http-server -p 8080   # ทดสอบในเครื่อง แล้วเปิด http://localhost:8080
```

## โครงสร้างไฟล์

```
index.html                 โครงหน้า
manifest.webmanifest, sw.js  PWA / ใช้งานออฟไลน์
assets/css/app.css         Design system + responsive + print (80mm / A4)
assets/js/store.js         ข้อมูล, utils, ตรรกะหลัก
assets/js/icons.js         ไอคอน SVG
assets/js/ui.js            modal, form, confirm, toast, print
assets/js/admin.js         รหัสแอดมิน, ปลดล็อก/ล็อก
assets/js/receipt.js       ใบเสร็จ 80mm และรายงาน A4
assets/js/printer.js       พิมพ์ตรงเครื่องพิมพ์ความร้อน (ESC/POS: USB / Serial / RawBT / รูปภาพ)
assets/js/views/*.js       แต่ละหน้า
assets/js/app.js           เมนู, router, event delegation
```
